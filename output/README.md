# Generated output

Successful local CLI generation always writes the validated transformation:

```text
output/{omop_table}.sql
```

For `output.format: dbt`, it also writes the deterministic dbt model contract:

```text
output/{omop_table}.yml
```

For `output.format: sql`, it writes the pinned OMOP CDM DDL bundle:

```text
output/ddl/create_tables.sql
output/ddl/primary_keys.sql
output/ddl/foreign_keys.sql
output/ddl/indexes.sql
```

PostgreSQL, Snowflake and BigQuery DDL comes from pinned OHDSI assets. Athena
DDL and dbt YAML are generated from `specs/target_schema`. None of these files
is generated by the AI model.

Generated SQL is intentionally ignored by Git because it may contain
environment-specific relation names or sensitive implementation details. A
non-authoritative example is available under `examples/generated/`.
